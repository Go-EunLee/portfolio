# Project
팀 프로젝트에서 **핵심 기능 개발과 코드 리뷰**에 집중하며, 프로젝트의 전반적인 품질을 높이는 데 기여했습니다. 백엔드 아키텍처 설계와 데이터베이스 관리 역할을 맡아 프로젝트의 안정성을 확보했습니다.

개인 프로젝트에서는 **전체 시스템의 설계와 구현**을 진행했습니다. 이 과정에서 새로운 기술을 배우고, **문제 해결 능력**을 키우는 경험을 쌓을 수 있었습니다.
<br> <br>

### 1. JOBPREP

>  JOBPREP은 취업이 처음인 취업 준비생을 위한 플랫폼입니다. 사용자들은 회사 지원 현황을 정리하고, 예상 면접 질문을 리스트화하며, 자신만의 자소서를 만들어갈 수 있습니다. 그리고 같은 취준생들을 위해 스터디를 운영하고 모집, 참여할 수 있습니다.
>
> 참여 인력 : 3인
> 
> 역할
> - 면접 및 마스터 자소서 CRUD API 설계 구현
> - OAuth 2.0 을 이용한 소셜 로그인(네이버, 구글, 카카오) 구현 
> - Redis Sentinel 환경 구축 및 관리 
>
> 
> Skill : Spring Boot, JPA, Java, MySQL, Redis, MongoDB, Docker, Jenkins, GCP

### 2. 여정

> 여정은 여행지에서의 감동과 추억을 함께 나누는 커뮤니티 플랫폼입니다.사용자들은 자신의 경험과 특별한 장소를 소개하고, 후기를 통해 자신의 여행 후기를 공유합니다. 또한 자신만의 여행 계획표를 작성해 세세한 여행 일정을 작성할 수 있습니다.
>
> 참여 인력 : 3인
> 
> 역할

> - 여행 플래너 작성  기능 개발
> - AWS 를 이용해 최종 배포 완료
> 
> Skill : Spring Boot, JPA, Java, MySQL, Redis, GitHub Actions, Docker, AWS

### 3. 대기열 웹사이트

> 대기열 웹사이트는 간편하고 효율적인 대기열 관리 시스템을 통해 사용자들에게 공정한 순서를 제공합니다. 특정 홈페이지에 접속하는 순간, 각 사용자에게 고유한 순번이 부여되며, 정해진 대기 조건에 따라 순차적으로 원하는 페이지로 리디렉션됩니다. 이 과정을 자동화하였습니다.
>
> 참여 인력 : 1인
> 
> 역할
> - Spring WebFlux의 비동기 논블로킹 구조로 대규모 트래픽에 대한 고성능 처리 구현
> - Html, Css를 사용한 직관적이고 반응형 대기열 인터페이스 제공
> - JavaScript를 활용한 사용자 상태 및 대기열 정보 동기화
> 
> Skill : Spring Boot, JPA, Java, Redis, Html, Css, JavaScript, Jmeter
